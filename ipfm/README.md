ipfm
=====

IP Flow Meter ([ipfm][1]) is a bandwidth analysis tool which outputs a list of hosts with their respective bandwith usage. IPFM uses libpcap and aims to be portable.

> [!CAUTION]
> RC buggy, upstream recommends to remove the package from Debian.

[1]: https://manpages.ubuntu.com/manpages/jammy/man8/ipfm.8.html
